AI-generated cases (Agent37)

The shop's own model, through the Agent37 LLM router, writes a fresh batch of shopkeeper messages nobody has seen before. Each one then goes through the real owner pipeline (the AI reads it first, the rules check it, then the khata) on its own throwaway demo shop, on the server. Nobody wrote an expected answer, so each case is checked against fixed rules: no crash, a reply to the owner, old entries untouched unless it is a fix, nothing written on a message the model marked as a question or unclear, every amount written is a number in the message, every khata written to is named in the message, udhaar never written as jama. The model's other labels (the amount it meant, an entry it expected) are shown as label and not counted as failures: the same model writes and reads, so they are a second opinion, not ground truth. A wrong amount that is still a number in the message ("3200 me se 1000 diye" written as 3200) only shows up as a label.
